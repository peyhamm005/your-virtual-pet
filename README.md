# Instructions
Click on the apple to feed him and prevent him from getting too hungry and click on the ball to play with him to prevent him from getting bored

# Download instructions
Download the zip file and extract it. Run Your Virtual Pet.exe to run the game. No install required. The game will begin in fullscreen. Press Escape to exit fullscreen. Press Escape again to exit the game.

# Fork instructions
If you want to make a fork on GitHub, feel free to fork the project. If you want to change something, then download the sb3 file from the latest release, load it into the Scratch offline or online editor, make the edits, save it to a new file, then upload the new file to TurboWarp Packager. To add the assets, rename the .sb3 to .zip and add everything inside to the assets.

# An easier way to fork
You can head over to the Scratch page for this project and remix it there. This is the same concept as a fork but much easier to understand.
